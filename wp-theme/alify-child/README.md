# ALIFY Child Theme (`alify-child`)

Official update-safe **WordPress Child Theme** for **`ALIFY`** (`Template: alify`).

## Installation

1. Upload and install **`alify.zip`** first (`Appearance → Themes → Add New → Upload Theme`) — do not delete the parent theme.
2. Upload **`alify-child.zip`** and click **Activate**.
3. Place any custom CSS inside `alify-child/style.css` and any custom PHP hooks/filters inside `alify-child/functions.php`.

All 22 templates, 7 `Alify Custom Field` Options Pages, 15 Local JSON Field Groups, 6 CPTs, Starter Content + Media Library Importer, Built-In SMTP Mailer, Leads CRM, 11 Shortcodes, and 8 Dynamic Gutenberg Blocks work automatically through the parent theme.
